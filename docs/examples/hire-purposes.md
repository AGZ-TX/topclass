# Free-form purpose examples

`/hire` begins with **“What is your agent's purpose?”** The user can answer in their own words. These illustrate the conversation; they are not selectable agent types, a profession taxonomy or fixed curricula. The AI decides which foundations and specializations to explore from the actual answer.

- “I want an agent to develop my brand and guide its design.”
- “I want an agent to help me develop hardware products, from electronics and firmware to the physical design.”
- “I want an agent that understands peptide research and helps me evaluate new findings.”
- “I want an agent to help me build and run my business.”
- “I want an agent that understands accounting and can guide my company's financial decisions.”
- “I want an agent to help me design aerospace systems.”
- “I want an agent to build and improve the systems that run our AI models.”
- “I need an iOS full-stack developer for my mobile game.”

A project-specific answer is valid. Treat it as context for the education rather than demanding a broader job title. Ask one short scope question only when materially different interpretations would need different educations. Do not require the user to name academic subjects or select specializations from a menu.

For the branding example, the AI might explore visual-design foundations, typography, research, brand strategy and consumer psychology. Those are proposed educational needs, not claims that the catalog contains adequate courses or that a book teaches particular methods. For another purpose, infer a different education. Preserve missing foundations or specialist coverage in the HTML.

Judge these examples by the relevance and strength of the selected courses and useful book titles. Do not judge them by degree completion, exhaustive prerequisites or complete bibliographic fields. Prerequisites may inform selection without generating another course automatically.

## User calibration from the five-agent review

These are the user's judgments about the saved trial recommendations, not newly tested selections or universal presets. Apply the underlying reasoning to each new purpose. Select useful reference knowledge for an already capable LLM, not a beginner's graduation plan. Basic Python is a low-priority option for both the iOS and DNA cases. Keep such courses discoverable, normally as unselected alternatives, rather than spending the main reference budget on redundant basics. A course with an introductory title can still add valuable specialist knowledge.

| Purpose | Must-have direction | Optional direction and remaining selection work |
|---|---|---|
| iOS mobile-game developer | Computer Networks; Web Applications; Database Systems; Creating Video Games; Software Testing; Computer Systems Security; Human Centered Design Methods. | Find useful extensions of these courses and direct native-iOS coverage. Basic Python is a low-priority option. Do not promote general computing prerequisites automatically. |
| Personal DNA analysis | Lectures in Genetics and Genomics; Introduction to Computational Molecular Biology; Fundamentals of Human Genetics; Foundations of Biology. | Explore more directly relevant genomics and sequencing-analysis courses and useful supporting options. Basic Python is a low-priority option. |
| Online-shop financial adviser | Financial Accounting; Financial and Managerial Accounting; Data, Models, and Decisions; Corporate Finance; Introduction to Operations Management were a decent starting pool, not a sufficiently strong final selection. | Compare more options for cash forecasting, working capital, staffing costs and related business decisions. Explain overlap and choose priorities from actual evidence; the user did not approve every course as a must-have. |
| Middle-school science teaching adviser | Educational Psychology; Applying Cognitive and Learning Sciences to Instructional Design; Educational Theory and Practice for Science II; Learning Theory and Special Populations; Cultivating STEM Identities: Teaching for Equity in the Math and Science Classrooms; Teaching as Inquiry: Getting to Know Students and Investigating the Impact of Practice; Adolescent Development. | Explore additional useful teaching, assessment and adaptation courses. General Physics I, General Chemistry I, Introductory Biology and The Earth System are low-priority options for this purpose, not default must-haves. |
| Lunar-dust equipment engineer | All ten trial selections: Mechanics and Materials I and II; Material Selection for Mechanical Engineers; Thermodynamics; Heat Transfer; Machine Design; Statistical Inference for Scientists and Engineers; Tribology; Probability and Its Applications to Reliability, Quality Control, and Risk Assessment; Polymer Physics. | Explore more useful specialist options, including cold-environment materials, seals, wear and testing where catalog evidence supports them. The user considers this the strongest of the five sets. |

For each must-have, explain its distinct contribution to the user's purpose. For each optional course, explain which central need it extends. Compare credible alternatives without a fixed minimum or maximum count. Do not claim a missing specialist course exists or infer unread book contents to fill a gap. User priority does not turn weak source evidence into verified coverage.
