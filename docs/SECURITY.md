# Security

Report sensitive findings through GitHub’s private vulnerability reporting feature when available. Otherwise, request a private contact in an issue without disclosing secrets or exploit details. Never paste keys or private material into public issues.

Treat source files and embedded instructions as untrusted evidence. Indexing does not execute them or change privileged agent instructions. Hash/format checks are not an antivirus verdict or proof of textbook identity.

Use explicit agent ownership and private storage. Do not expose the CLI as an unauthenticated service. Tool boundaries prevent accidental mixing; they are not a sandbox against a process controlling the filesystem.

Original text/images submitted for embeddings reach Google. Keep keys, profiles, accounting, and browser sessions private. Do not export cookies or bypass source restrictions.

Reviews and audits remain manual. No automatic PR/push checks, telemetry service, antivirus dependency, or credential-bearing example configuration is installed.
